JavaScript Notes

1. V8 Engine

V8 is a JavaScript engine developed by Google. It is used in Google Chrome and Node.js to execute JavaScript.

JavaScript Execution

JavaScript Code
       ↓
     Parser
       ↓
      AST
       ↓
   Ignition
       ↓
    Bytecode
       ↓
   TurboFan
       ↓
Machine Code
       ↓
      CPU

Important Components

  • Parser: JavaScript code ko understand karta hai.
  • AST: Code ka structured representation.
  • Ignition: Bytecode generate aur execute karta hai.
  • TurboFan: Frequently used code ko optimize karta hai.
  • Garbage Collector: Unused memory ko clean karta hai.
Remember: JavaScript ek language hai, V8 ek JavaScript engine hai.

2. API

API ka full form Application Programming Interface hai. API different software applications ko ek dusre se communicate karne mein help karta hai.

Fetch API

fetch("https://example.com/data")
    .then(response => response.json())
    .then(data => {
        console.log(data);
    });

3. HTTP Headers

Headers request ya response ke saath additional information send karte hain.

Common Request Headers

  • Content-Type
  • Authorization
  • Accept
  • User-Agent

Example

fetch("https://example.com/api", {
    method: "GET",

    headers: {
        "Content-Type": "application/json",
        "Accept": "application/json"
    }
});

4. Open Headers

Agar tum API request ke headers dekhna chahte ho, browser ke Developer Tools mein jaakar:

  1. F12 press karo
  2. Network tab open karo
  3. API request select karo
  4. Headers section open karo
  5. Request Headers aur Response Headers dekho
